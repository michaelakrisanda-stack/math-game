# 🚀 Math Blast!

A math practice game for kids entering **second grade**. No internet, no installs, no accounts — it's one file that runs right on your computer.

## How to play it on your computer

1. Download `index.html` from this repository (or clone the repo).
2. Double-click `index.html` — it opens in your web browser (Chrome, Edge, Safari, Firefox all work).
3. That's it! It works completely offline.

Tip: put a shortcut to the file on the desktop so your child can start it themselves.

## What it practices (2nd grade skills)

| Mission | Skill |
|---|---|
| ➕ Addition | Adding within 100 |
| ➖ Subtraction | Subtracting within 100 |
| ❓ Missing Number | Solving `? + 4 = 12` style problems (early algebra thinking) |
| ⚖️ Bigger or Smaller | Comparing numbers with `>`, `<`, `=` |
| 🌟 Super Mix | A little of everything, including skip counting (2s, 5s, 10s…) |

## Difficulty levels

- **🐣 Easy** — numbers within 20. Great warm-up for a rising second grader.
- **🦊 Medium** — two-digit numbers within 100, *without* carrying/borrowing. This is the heart of second-grade math.
- **🐉 Hard** — two-digit problems *with* regrouping (carrying and borrowing), plus comparing 3-digit numbers.

## How the game encourages practice

- Each round is 10 questions with a progress bar.
- Stuck? The **💡 Hint button** teaches the strategy for that exact problem ("add the tens first: 30 + 50, then the ones…") without ever giving the answer. Hinted questions earn 5 points instead of 10, so there's still a reason to try solo first.
- Correct answers earn points; 3+ in a row lights a 🔥 streak bonus.
- Wrong answers gently show the correct one — no penalties, just encouragement.
- Rounds end with 1–3 stars, confetti, and cheerful sounds.
- High scores are saved on your computer, so there's always a score to beat.
